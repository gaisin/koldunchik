# Колдунчик

3D-тренажёр настройки парусов круизной яхты 13 м — шлюп с бермудским вооружением, по типу Dufour 430.

**Открыть:** https://gaisin.github.io/koldunchik/

## Что можно делать

- Задавать силу и направление ветра, сдвигать его на ±10/20° (с пометкой «заход» или «отход» для текущего галса), включать порывы и случайные события.
- Рулить: «Привестись», «Увалиться», повороты оверштаг и фордевинд.
- Настраивать паруса в двух режимах:
  - **Быстрые настройки** — ползунки: шкот и каретка стакселя, раскрытие (закрутка), гика-шкот, погон, оттяжка гика, аутхол, фал, рифы, ахтерштаг, бабочка на фордевинде.
  - **Палуба** — пианино со стопорами, лебёдки на рубке и основные лебёдки, каретки на погонах, погон гика-шкота, таль ахтерштага. Стопор пропускает снасть на выбирание, а травят только через лебёдку при открытом стопоре.
- Смотреть на колдунчики стакселя и задней шкаторины грота, виндекс и струйки вымпельного ветра.
- Получать оценку настройки в процентах и по десяти пунктам. Подсказка к пункту открывается по нажатию.
- Проходить 12 сценариев: заход и отход ветра на разных курсах, «раул», повороты, усиление и ослабление ветра, шквал. После каждого — разбор: что нужно было сделать и почему.

## Как запустить у себя

Откройте `index.html` в браузере — сервер не нужен. Нужен браузер с WebGL (любой современный).

## Как устроено

Статический сайт без сборки: HTML, CSS и обычные скрипты.

| Файл | Что внутри |
|---|---|
| `js/sim.js` | Модель без графики: поляра скоростей, вымпельный ветер, геометрия парусов из настроек, аэродинамика по пяти сечениям каждого паруса, крен из баланса моментов, скорость, баланс руля. Модель палубы: стопора, лебёдки, нагрузки на снасти и ограничения. Оценка, подсказки, сценарии. Работает и в Node. |
| `js/scene.js` | 3D на Three.js: корпус, рангоут, паруса с пузом, скруткой и заполаскиванием, колдунчики, море с волнами, ветер, камеры. |
| `js/ui.js` | Интерфейс: приборы, ползунки, схема палубы, сценарии и главный цикл. |
| `css/style.css` | Стили, светлая и тёмная тема, раскладка для телефона. |
| `vendor/` | Three.js r147 и OrbitControls (лицензия MIT). |

Прогресс по сценариям хранится в `localStorage` браузера.

## Ограничения

Модель учебная и упрощённая. Поляра и силы подобраны под круизную яхту 13 м, цифры в подсказках ориентировочные. Логика колдунчиков и порядок работы со снастями соответствуют практике.
